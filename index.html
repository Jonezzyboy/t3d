    How to play
    
      
      
    1. Every day brings one kata: a function stub and a hidden stack of tests. You start with the first test only.
      2. 
      
    2. Write just enough code to turn it green, then press Run tests. Each run counts toward your score.
      3. 
      
    3. When everything shown is green, reveal the next test. Revealing is free, and if your code already handles it, it lights up green straight away.
      4. 
      
    4. Clear every test in as few runs as you can. Par is one run per test; a general solution can beat it.
      5. 
      
    5. Once the last test passes, runs stop counting. Refactor as much as you like, then share your grid.
